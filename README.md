
# IT313 Modern JavaScript (ES6+) Essentials

## Problem
This project checks the enrollment eligibility of IT313
enrollees using their prelim, midterm, and final grades.

An enrollee is PASSING if their average is 75 or above.
Otherwise, the enrollee is placed on PROBATION.

## Approach
The program uses ES6+ features including const, arrow
functions, template literals, destructuring, spread/rest
operators, and the map, filter, and reduce array methods.

It uses named and default ES module exports, Promises,
async/await, and try/catch for asynchronous error handling.

## Files
- gradeUtils.js: Computes averages and checks passing status.
- index.js: Retrieves the records and prints the report.

## Requirements
Install Node.js before running the program.

## How to Run
Open the project folder in the terminal and run:

node index.js

The gradeUtils.js file is imported automatically by index.js.
